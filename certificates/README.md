# Фото сертифікатів

Додайте сюди зображення сертифікатів. Сторінка автоматично завантажить файли з такими назвами:

- `1.jpg`
- `2.jpg`
- `3.jpg`

Підтримуються формати JPG, JPEG, PNG і WebP. Нумеруйте файли послідовно, без пропусків. Щоб вказати назву та організацію для картки, відредагуйте `DOC_TITLES` у `index.html`.
